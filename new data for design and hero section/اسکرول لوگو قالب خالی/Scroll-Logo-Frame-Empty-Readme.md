# اسکرول+لوگو+قاب — پوستهٔ خالی

فقط قاب، اسکرول و لوگو نمایش داده می‌شوند. فضای مرکزی خالی است؛ داشبورد، منو، نمودار و داده‌های نمونه حذف شده‌اند. نوشتهٔ حالت روز/شب زیر پنل هم حذف شده است؛ اجزای خود لوگو و اسکرول از نسخهٔ تأییدشده باقی مانده‌اند. نسخهٔ فریز‌شدهٔ «اسکرول+لوگو» و فایل‌های اصلی آن تغییر نکرده‌اند.

## اجرای ساده

فایل Scroll-Logo-Frame-Empty.html را باز کنید. پوشهٔ assets و CSS باید کنار آن باشند. پیش‌فرض حالت شب است؛ برای حالت روز، هنگام میزبانی صفحه `?theme=day` را به نشانی اضافه کنید.

## استفاده در Next.js / React

فایل ScrollLogoFrameEmpty.mjs را به components کپی کنید. فایل CSS همراه را در layout اصلی وارد کنید. دو فایل پوشهٔ assets را در public/pezeshkon-vital-frame قرار دهید.

```jsx
import {ScrollLogoFrameEmpty} from './ScrollLogoFrameEmpty.mjs';
import './Scroll-Logo-Frame-Empty.css';

// خروجی کاملاً خالی در مرکز:
<ScrollLogoFrameEmpty theme="dark" />

// محتوا بعداً در فضای رزروشده قرار می‌گیرد:
<ScrollLogoFrameEmpty theme="day">{children}</ScrollLogoFrameEmpty>
```

کلاس‌های قاب با pez-shell نام‌گذاری شده‌اند تا با استایل‌های پروژه برخورد کمتری داشته باشند. قاعدهٔ html,body انتهای CSS برای نمونهٔ مستقل است؛ هنگام ادغام در پروژه، آن قاعده را بر اساس layout میزبان حذف یا تنظیم کنید.

اندازه‌ها در دسکتاپ و موبایل عمودی/افقی تطبیق می‌یابند. محتوا داخل قاب پیمایش می‌شود. این پوسته ظاهر ثابت دارد؛ برای عدد و بیکون متصل به دادهٔ واقعی باید مرحلهٔ اتصال کامپوننت پویا در پروژهٔ اصلی تکمیل شود.

SVG شامل لوگوی تصویری است و کاملاً برداری نیست. هیچ اتصال شبکه‌ای یا دادهٔ واقعی در این پوسته وجود ندارد.
