## 🏛️ معماری سیستم

اکوسیستم پزشکآن مطابق منشور طراحی و استانداردهای مصوب سلامت دیجیتال به سه لایه تفکیک شده است:

1. **وب‌سایت و پرتال عمومی (Pezeshkan Acquisition Portal):**
   - لایه جذب کاربر، معرفی خدمات مطب‌ها، نوبت‌دهی آنلاین، آموزش بیماران و تبدیل مخاطب به بیمار/کاربر.
   - تجربه‌ کاربری مدرن با موتور سه‌بعدی Three.js، فریم‌ورک انیمیشن GSAP و اسکرول روان Lenis.

2. **اپلیکیشن بالینی و پرونده الکترونیک (Pezeshk-On EMR & HIS Bridge):**
   - لایه تخصصی درمان، تریاژ هوشمند، ارزیابی مطب و کلینیک (`/start`) و معرفی سیستم‌های یکپارچه مدیریت مطب.

3. **هاب محتوایی و مجله سلامت بالینی (`/mag`):**
   - ۹ پیلار تخصصی دانش پزشکی، خبرنامه خودکار، استودیو مدیریت محتوای بالینی بر پایه Tiptap v2 و موتور تبدیل خواننده به بیمار (Lead Conversion Engine).

## 🎨 هسته بصری و دیزاین سیستم (Clinical Dark DNA)

طراحی بصری این اکوسیستم بر پایه **کنتراست بالینی تاریک (Clinical Dark)** و نسبت ۷۰/۲۰/۱۰ استوار است:

- **فیروزه‌ای حیاتی (`#00FFFF`):** داده‌ها، تکنولوژی پزشکی و المان‌های فعال تعاملی.
- **سبز تپش حیات (`#00E599`):** سلامت، ارزیابی موفق و نشان‌های تایید بالینی.
- **کهربایی هشدار (`#F59E0B`):** تریاژ درجه دو، اطلاعیه‌ها و هشدارهای مراقبتی.
- **قرمز اورژانس (`#EF4444`):** وضعیت‌های بحرانی پزشکی و پیام‌های حساس امنیتی.
- **تایپوگرافی:** فونت استاندارد وزیرمتن (Vazirmatn) با هندسه کاملاً راست‌به‌چپ (RTL).
- **افکت‌های عمق:** شیشه‌ای تیره (Glassmorphism Dark) با بلور زمینه و حاشیه‌های میکرونی نورانی.

## 🛡️ امنیت و سپر دفاعی سرور (`server.py`)

سرور پروداکشن پایتون دارای مکانیزم‌های دفاعی جامع سطح سازمانی است:
- **احراز هویت PBKDF2-SHA256:** رمزنگاری چندلایه کلمات عبور و نشست‌های دارای توکن امنیتی غیرقابل دستکاری.
- **نرخ محدودسازی لغزان (Rate Limiting):** حفاظت بلادرنگ در برابر حملات Brute-Force و بات‌های اسپم.
- **نرمال‌سازی سخت‌گیرانه مسیرها:** ممانعت کامل از آسیب‌پذیری نفوذ به دایرکتوری‌ها (Path Traversal).
- **پاکسازی ورودی‌ها:** مقابله چندلایه با تزریق کدهای مخرب (Stored XSS).
- **هدرهای امنیتی مدرن:** تزریق خودکار CSP, HSTS, X-Frame-Options, X-Content-Type-Options و Permissions-Policy.
- **عملیات فایل اتمیک:** استفاده از قفل‌های همزمانی (Concurrency Locks) برای محافظت از سلامت فایل‌های JSON.
- **پشتیبانی ابری:** آماده اتصال به باکت‌های S3، Cloudflare R2 و MinIO برای ذخیره‌سازی رسانه‌ها.

## 📈 استاندارد سئو پزشکی و E-E-A-T

پروژه به طور کامل با آخرین الزامات الگوریتم‌های سلامت گوگل سازگار است:
- **ساختار داده‌ای Schema.org:** اسکیماهای تفکیکی `MedicalWebPage`، `Physician`، `MedicalCondition` و `MedicalGuideline`.
- **سند محتوای ماشین llms.txt:** ارائه ساختار استاندارد اطلاعات برای موتورهای هوش مصنوعی و مدل‌های زبانی.
- **نقشه سایت پویا و فایل Robots:** پیکربندی دقیق دسترسی خزنده‌های جستجو به آدرس‌های معتبر و مسدودسازی بخش‌های پنل.

## 🚀 راه‌اندازی سریع پروژه

### روش اول: اجرای مستقیم در ویندوز
کافیست روی فایل `START_PROJECT.bat` دوبار کلیک کنید. سرور به صورت خودکار راه‌اندازی شده و صفحات پرتال، مجله و پنل ادمین را در مرورگر شما باز خواهد کرد.

### روش دوم: اجرای دستی با پایتون
```bash
# نصب پیش‌نیازها
pip install -r requirements.txt

# اجرای سرور پروداکشن
python server.py
```
سپس به آدرس‌های زیر در مرورگر مراجعه کنید:
- **پرتال اصلی:** `http://localhost:3000/`
- **مجله سلامت:** `http://localhost:3000/mag`
- **استودیو مدیریت محتوا:** `http://localhost:3000/admin`

### روش سوم: استقرار با Docker
```bash
cd deploy
docker-compose up -d
```
