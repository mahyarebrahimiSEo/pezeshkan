# سند دوم: معماری پالت رنگی مدرن و توکن‌های شیشه مایع (Liquid Glass 2026)
> تدوین پالت اختصاصی کلینیکال بر اساس سمپل‌های برتر دریبل، اکوسیستم Apple Health و استاندارد اپتیکال شیشه مایع

---

## ۱. فلسفه پالت رنگی جدید (Dignified Clinical Authority)

برای رهایی از رنگ‌های ناسازگار فعلی (فسفری اسیدی، زرد تند، قرمز خشن و آبی نوزادی)، پالت جدید بر اساس ۳ اصل کلیدی معماری بصری پایه گذاری شده است:

- قانون بوم خنثی و باوقار (۸۵٪ سطح بصری):
  رنگ زمینه نباید با کارت‌ها و محتوا رقابت کند. در حالت روز از طیف‌های آرامش‌بخش نقره‌ای-یخی استفاده می‌شود و در حالت شب از ته‌رنگ‌های گرانیتی و اسلیت جراحی که چشم پزشک و بیمار را خسته نکند.
- رنگ سازمانی کبالت هوشمند (۱۰٪ کنش و هویت):
  رنگ اصلی برند پزشک‌آن، آبی کبالت عمیق و پرستیژ پزشکی است که بالاترین سطح اطمینان، دقت بالینی و هوش نرم‌افزاری را تداعی می‌کند.
- نشانگرهای کاربردی به عنوان علائم نگارشی (۵٪ رنگ‌های کمکی):
  رنگ‌های مکمل (سبز حیات، فیروزه‌ای تله‌متری، بنفش کروماتیک) صرفاً برای نمایش وضعیت‌ها، لبه‌های بازتاب نور و پالس‌های داده به کار می‌روند، نه برای رنگ‌آمیزی بی‌دلیل پس‌زمینه‌ها.

## ۲. مشخصات پالت رنگی تم روز (Radiant Clinical Light)

این تم برای محیط‌های کاری روزانه، مانیتورهای مطب پرنور و موبایل بیماران طراحی شده است:

- بوم اصلی صفحه (Canvas Background):
  کد رنگی: `#F6F9FC` به همراه گرادیان نامحسوس تا `#EDF2F7` (جایگزین آبی کدر #c6eefb).
  این بوم حسی فوق‌العاده تمیز، استریل و بدون آلودگی بصری ایجاد می‌کند.
- رنگ اصلی هویت برند (Brand Cobalt):
  کد رنگی: `#0066FF` با تغییر سایه دکمه‌ها روی `#0052CC`.
  این رنگ نماد پلتفرم سلامت دیجیتال و دارای بیشترین کنتراست ارگونومیک بر روی پس‌زمینه‌های سفید است.
- کارت‌های شیشه‌ای روز (Frosted Ice Glass):
  پس‌زمینه: `rgba(255, 255, 255, 0.72)` با فیلتر `backdrop-filter: blur(24px) saturate(180%)`.
  لبه بالایی بازتاب نور: `border-top: 1px solid rgba(255, 255, 255, 0.95)`.
  سایه شناور ملایم: `box-shadow: 0 16px 36px -8px rgba(15, 23, 42, 0.06), 0 0 0 1px rgba(0, 102, 255, 0.08)`.
- رنگ‌های وضعیت و سیگنال‌های بالینی (Clinical Signals):
  - سبز سلامت و تاییدیه‌ها: `#059669` (سبز زمردی عمیق و خوانا، جایگزین فسفری اسیدی).
  - فیروزه‌ای تله‌متری و نوبت‌دهی: `#0284C7` و هایلایت `#00E5FF`.
  - هشدار هوشمند و یادآورها: `#D97706` (کهربایی موقر و جدی، جایگزین زرد براق).
  - خطای بحرانی یا لغو نوبت: `#E11D48` (رز بالینی نرم، جایگزین قرمز تند D30E00).
- رنگ متون فارسی:
  - تیترهای اصلی: `#0F172A` (سرمه‌ای بلک خوانا با کنتراست AAA).
  - پاراگراف‌ها و توضیحات: `#334155` (خاکستری تیره با خوانایی بالا).
  - برچسب‌های کمکی: `#64748B`.

## ۳. مشخصات پالت رنگی تم شب (Deep Surgical Dark)

این تم حس یک اتاق جراحی مدرن و داشبورد مانیتورینگ بیمارستانی در شب را القا می‌کند:

- بوم اصلی صفحه (Deep Space Canvas):
  کد رنگی: `#080D1A` تا `#0D1527` (جایگزین سورمه‌ای کدر قدیمی #061c29).
  میدان عمیق تیره که زمینه را برای درخشش شیشه و المان‌های ۳D آماده می‌کند.
- نورهای محیطی زیرین (Ambient Vital Mesh):
  لایه‌های محو نوری پشت کارت‌های شیشه‌ای شامل هاله‌های فیروزه‌ای `rgba(0, 229, 255, 0.08)` و ارغوانی `rgba(168, 85, 247, 0.07)` که مانع از سیاه شدن شیشه می‌شوند.
- کارت‌های شیشه‌ای شب (Liquid Obsidian Glass):
  پس‌زمینه: `linear-gradient(135deg, rgba(255, 255, 255, 0.08) 0%, rgba(15, 23, 42, 0.42) 100%)`.
  فیلتر ترکیبی: `backdrop-filter: blur(28px) saturate(190%) contrast(105%)`.
  لبه بازتابی کریستالی: `border-top: 1px solid rgba(255, 255, 255, 0.32)`.
  سایه لبه زیرین: `border-bottom: 1px solid rgba(0, 0, 0, 0.4)`.
  سایه معلق: `box-shadow: 0 24px 50px -12px rgba(0, 0, 0, 0.75), inset 0 1px 1px rgba(255, 255, 255, 0.25)`.
- رنگ‌های وضعیت و سیگنال‌های شب:
  - سبز مانیتورینگ علائم حیاتی: `#10B981`.
  - فیروزه‌ای پالس و عروق: `#00E5FF`.
  - ارغوانی کروماتیک (مشابه شکست نور قلب شیشه‌ای): `#C084FC`.
  - کهربایی آماده‌باش: `#FBBF24`.
- رنگ متون شب:
  - تیترهای اصلی: `#F8FAFC` (سفید الماسی بدون خیرگی چشم).
  - متن‌های ثانویه: `#94A3B8`.
  - متون غیرفعال: `#64748B`.

## ۴. توکن‌های استاندارد CSS برای پیاده‌سازی سریع (Drop-in CSS Variables)

این مقادیر مستقیماً جایگزین کدهای مغشوش ابتدای `portal/shared.css` می‌شوند:

```css
/* تم روز مدرن پزشک‌آن (Radiant Clinical Light) */
:root, [data-theme="light"] {
  --canvas-bg: #F6F9FC;
  --surface-glass-bg: rgba(255, 255, 255, 0.72);
  --surface-glass-border: rgba(255, 255, 255, 0.90);
  --surface-glass-rim: rgba(0, 102, 255, 0.12);
  
  --brand-primary: #0066FF;
  --brand-primary-hover: #0052CC;
  --brand-cyan: #0284C7;
  --brand-purple: #9333EA;
  
  --status-stable: #059669;
  --status-warning: #D97706;
  --status-critical: #E11D48;
  
  --text-headline: #0F172A;
  --text-body: #334155;
  --text-muted: #64748B;
  
  --glass-filter: blur(24px) saturate(180%);
  --shadow-floating: 0 16px 36px -8px rgba(15, 23, 42, 0.08), 0 0 0 1px rgba(0, 102, 255, 0.06);
}

/* تم شب مدرن پزشک‌آن (Deep Surgical Dark) */
[data-theme="dark"] {
  --canvas-bg: #080D1A;
  --surface-glass-bg: linear-gradient(135deg, rgba(255, 255, 255, 0.08) 0%, rgba(15, 23, 42, 0.44) 100%);
  --surface-glass-border: rgba(255, 255, 255, 0.18);
  --surface-glass-rim: rgba(255, 255, 255, 0.32);
  
  --brand-primary: #38BDF8;
  --brand-primary-hover: #0284C7;
  --brand-cyan: #00E5FF;
  --brand-purple: #C084FC;
  
  --status-stable: #10B981;
  --status-warning: #FBBF24;
  --status-critical: #F43F5E;
  
  --text-headline: #F8FAFC;
  --text-body: #94A3B8;
  --text-muted: #64748B;
  
  --glass-filter: blur(28px) saturate(190%) contrast(105%);
  --shadow-floating: 0 24px 50px -12px rgba(0, 0, 0, 0.75), inset 0 1px 1px rgba(255, 255, 255, 0.25);
}
```

با این توکن‌ها، هماهنگی بصری کاملی بین المان‌های سه‌بعدی هیرو و تمام کارت‌های سایت ایجاد می‌شود و شلختگی رنگی فعلی به طور ریشه‌ای پایان می‌یابد.
