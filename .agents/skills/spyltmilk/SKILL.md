# SpyltMilk Studio Frontend Skill

Specialized skill for production-grade modern studio UI development, responsive motion layouts, and high-impact web interactions inspired by Tubik Studio's award-winning `spylt.com`.

## When to Activate
- Crafting creative agency/studio-level product landing pages and presentation sections.
- Implementing dynamic interactive cursor effects, magnetic buttons, and fluid SVG line animations.
- Structuring high-impact typography with responsive fluid font scaling (clamp).
- Adding subtle parallax and scroll-linked depth to cards and media slices.

## Key Principles & Architectural Patterns

### 1. Fluid Typography & Editorial Layout
- Responsive font size clamping: `clamp(2rem, 5vw, 4.5rem)` for primary display headings.
- Intentional whitespace framing: wide margins with compact, highly scannable focal content.
- Asymmetrical photo and UI crop placement with soft rounded framing.

### 2. Interactive Micro-Interactions
- Magnetic snap-on-hover for primary action buttons.
- Smooth SVG stroke animations for progress indicators and section dividing lines.
- Subtle cursor-following radial glow accents on dark and light surfaces.
