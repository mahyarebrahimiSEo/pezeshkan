# Capsule UI & Animation Skill

Specialized skill for creating Awwwards-caliber interactive web experiences, kinetic UI motion, and fluid capsule layouts inspired by the award-winning `capsule.moyra.co` showcase.

## When to Activate
- Implementing sophisticated GSAP ScrollTrigger timelines and staggered entrances.
- Building floating capsule navigation bars, interactive pill docks, and elastic buttons.
- Designing responsive, asymmetric Bento Grid layouts with rich interactive states.
- Replicating modern Awwwards-style micro-interactions and smooth scroll choreography.

## Core Visual Patterns

### 1. The Floating Capsule Dock
Floating navigation bar encapsulated in an ultra-clean pill geometry:
- Rounded full (`rounded-full`) with frosted light glass or smoked dark glass backdrop.
- Specular top rim light (`border-t border-white/80`) with soft ambient blue diffuse shadow.
- Elastic spring hover states on active circular badges.

### 2. GSAP Scroll Choreography
- Staggered card reveals with subtle scale and translateY dampening.
- Kinetic typography reveal on scroll enter: split headings with overflow-hidden mask.
- Smooth scrub pinning for showcase sections.

### 3. Asymmetric Bento Grid
- Varied aspect ratios (2:1, 1:1, 1:2) with uniform gap rhythm (16px to 24px).
- Internal card depth: layered subtle radial gradients and micro-textured backgrounds.
